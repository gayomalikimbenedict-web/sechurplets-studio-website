What’s included
  • The Time Zone Sync Engine template with its script already installed.
  • A Genesis menu with three items: Setup Continents, Run the world, and Goodbye world.
  • Seven continent tabs once you run setup: ASIA, AFRICA, ANTARCTICA, EUROPE, NORTH AMERICA, OCEANIA, and SOUTH AMERICA.
  • For each of the 141 locations: Country / Territory, Time Zone, Day (Today), Date, Time (HH:MM:SS), and Parts of the Day.
How it works
  1. Open your copy of the template, choose Genesis, then Setup Continents, and confirm the message.
  2. Open the continent tab you want to watch.
  3. Choose Genesis, then Run the world. A sidebar opens, and the clock fills in and keeps ticking.
  4. Close the sidebar to stop the clock. Run it again any time.
  5. Goodbye world removes everything and leaves one blank tab called The Void. Use it only when you want to start over.
Good to know
  • The clock updates only the continent tab you are viewing, and only while the sidebar is open.
  • Setup Continents removes any tab that is not one of the seven continent tabs, so use the template in its own spreadsheet.
  • Goodbye world permanently deletes all tabs and cannot be undone.
  • Each location uses one fixed standard time offset. Daylight saving changes are not applied automatically, and places with several time zones (for example Russia and Indonesia) show one zone.
  • The list has 141 locations. It does not include every country (Africa and Europe have 20 each, for example).
  • Dates are shown as MM-DD-YYYY.
Before you buy

How you get it, and what to expect

How you get it

After you order and pay, we send you a link. It opens a Make a copy screen in Google Sheets. The template then lives in your own Google account, and you can use it right away.

First time you open it

Google shows a screen saying ‘Google hasn’t verified this app’. This is normal for a template you copy yourself. Click Advanced, then Go to [tool name] (unsafe), then Allow. The script works on that spreadsheet only.

What you need

A free Google account and Google Sheets. A computer is recommended.

What it does not do

  • It works in Google Sheets only, with no Excel version.
  • It does not connect to your calendar, chat tools, or any other system, and you do not paste in any data.
  • It does not schedule meetings or convert times you type in. It displays the current time for each location.
  • Nothing is sent to Sechurplets Studio. It runs inside your own copy of the sheet.
FAQ
Do I need to paste any data?

No. The location list is built in when you run Setup Continents.

Does the clock keep running when I close the sidebar?

No. Close the sidebar to stop it, and choose Run the world to start it again.

Will it delete my other tabs?

Setup Continents removes any tab that is not one of the seven continent tabs, so use the template in its own spreadsheet.

Can I watch more than one continent at once?

The clock updates the continent tab you are viewing. Switch tabs to watch another one.
